The examples catalog has one runnable example for every component, SVG element, and common task. Every `dil` block is a complete, independent document, and the OpenDIL repository's tests parse and run each one. Load the catalog with `agentSpecExamples` from `@snackbit/opendil/lib`, and use single examples as few-shot examples or retrieval results. Examples declare names for the whole document, so rename the declarations before you combine two of them. The data in the examples is invented.

Download the raw file at [`/agent-spec.examples.md`](/agent-spec.examples.md). See [Agent Spec](/docs/agent-spec/) for loading the spec, and [Prompting and evaluation](/docs/prompting/) for using examples in prompts.
