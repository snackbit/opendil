The full spec extends the [primary spec](/docs/agent-spec/) with a block for each component, composition, callback, and task. Each block starts with a heading such as `Component: slider`, `Composition: table > table-row > table-cell`, `Callback: slider.onChange`, or `Task: output-review`, so you can search it or retrieve one block at a time. Load it with `agentSpecFull` from `@snackbit/opendil/lib`. At about 83 KB, use it when your context budget allows, or retrieve only the blocks your model needs.

Download the raw file at [`/agent-spec.full.md`](/agent-spec.full.md), or go back to the [Agent Spec](/docs/agent-spec/) overview.
