## NodeGraph

<LiveExample id="graph" client:only="react" />

`content.nodes` contains `{ id, label, sub?, x?, y? }` objects. `content.edges` contains `{ id?, source, target, label? }`. `selectedId` controls selection; `onSelect` receives the selected node's string ID.

The graph spaces nodes to keep labels and connectors usable. It includes an equivalent button selection path beneath the canvas. Keep descriptions in `sub` and use meaningful node labels.

## Mermaid

<LiveExample id="mermaid" client:only="react" />

`Mermaid.source` is a string. Rendering uses strict security settings, text labels, and sanitized SVG. Source is bounded to 8,192 characters and 100 edges; interactive directives and unsafe styling/HTML are rejected.

## SVG

<ExampleSource id="vector" />

The supported vocabulary includes `svg`, `g`, `defs`, `marker`, `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, `text`, `tspan`, `linearGradient`, and `stop`. Only allowlisted SVG attributes are forwarded. External links, raw HTML, scripts, and arbitrary event attributes are not supported.

Provide a nearby textual explanation for diagrams whose meaning is important to the task.
