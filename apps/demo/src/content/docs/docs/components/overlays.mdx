Wrap the trigger button in `popover-trigger` and the content in `popover-content`, within one `popover`. Content supports `side="top"` or the default bottom, and `align="end"` or the default center.

Overlays stay inside the renderer's styling scope, including its ShadowRoot or frame. They support keyboard opening, Escape dismissal, collision handling, and focus restoration. Keep trigger labels meaningful and avoid placing essential information only in a hover interaction.
