| Tag           | Attributes                                                                   | Callback value                     |
| ------------- | ---------------------------------------------------------------------------- | ---------------------------------- |
| `input`       | `value`, `onChange`, `placeholder`, `aria-label`, `disabled`                 | String.                            |
| `slider`      | `value`, `onChange`, `min`, `max`, `step`, `marks`, `aria-label`, `disabled` | Number.                            |
| `checkbox`    | `checked`, `onChange`, `disabled`, `lineThrough`; children supply its label  | Boolean.                           |
| `radio-group` | `value`, `onChange`, `direction`, `aria-label`; contains `radio` children    | Selected string.                   |
| `radio`       | `value`; children supply its label                                           | Selection is handled by its group. |

`segmented-control` accepts `options` objects such as `{ value: "eu", label: "Europe" }`. Slider marks use `{ label: "…" }` entries. Callback arguments are DIL values, not browser events. Set `lineThrough={false}` when a checkbox represents a preference rather than a completed task.

Provide explicit `aria-label` values for inputs, sliders, and groups. A placeholder is not a persistent label. Controls retain their native edit feedback while the worker updates dependent output, and remain disabled until their definition is ready.
